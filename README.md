# pingdata

Ping HTML/Markdown data fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/pingdata/

## Install / run

```bash
git clone https://github.com/theworker02/pingdata.git
cd pingdata
node src/cli.js
node --test
```
